# Kanal Entegrasyon Paneli — Kavramsal Önizleme

Trendyol, Hepsiburada ve WooCommerce siparişlerini, stok durumunu ve kâr/zararı tek ekranda birleştiren bir yönetim panelinin tek dosyalık kavramsal önizlemesi.

- Tarih aralığı ve kanal filtreleri, net kâr trendi, kanal bazlı sipariş dağılımı, son siparişler ve kritik stok uyarıları
- Tüm veriler örnek/temsilidir; hiçbir mağazaya veya API'ye bağlanmaz
- Anılan marka adları yalnızca kanal örneği olarak kullanılmıştır; ilgili şirketlerle bağlantı yoktur
- Bağımlılık yok; `index.html` dosyasını tarayıcıda açmak yeterli
